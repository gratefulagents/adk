# Trace-store fixture provenance

`sdk-store.json` is generated by `scripts/trace-reference/main.go` using
Grateful Agents SDK v0.0.115, authoritative revision
`1dc92b73900fac74dc357a938e4b5eee6392b418`, specifically
`pkg/agentsdk/tracestore`. License: GPL-3.0-only, retained in the repository
LICENSE and `docs/migration/licenses/sdk-LICENSE`.

The fixture records storage documents and category/artifact bytes, not execution
of an evaluation adapter. JSON object ordering and numeric spelling are compared
semantically. Run `python3 scripts/trace-reference/check.py` to independently
regenerate and compare without changing the committed fixture or SDK baseline.


`sdk-writer.json` is independently generated by `writer.go` from the same pinned
SDK's TraceWriter. It removes wall-clock timestamps and tool elapsed durations,
retaining generation duration, original snapshot bytes, category fields,
metadata digests, instruction artifacts and health counters.

`sdk-otel.json` is independently generated by `otel.go` from the same pinned
SDK's OpenTelemetry processor and stdout exporter. It retains span names,
attributes and statuses, excluding randomly generated OTel identifiers and
wall-clock timing. The fixture generator redirects its own stdout descriptor
on Linux to capture the real Go exporter. It does not contact a collector.
All generators and derived fixtures retain the SDK's GPL-3.0-only provenance.
