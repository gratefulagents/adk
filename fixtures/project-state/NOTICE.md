# Project-state fixture provenance

These synthetic, public test vectors were generated by `generate.go` using the
actual public Go SDK projectstate and memory APIs. No production state, credentials,
private conversations, or provider responses are included. The fixture embedder is
a deterministic local function; no external provider is contacted.

Source: `github.com/gratefulagents/sdk`, revision
`1dc92b73900fac74dc357a938e4b5eee6392b418` (baseline v0.0.115):

- https://github.com/gratefulagents/sdk/tree/1dc92b73900fac74dc357a938e4b5eee6392b418/pkg/agentsdk/projectstate
- https://github.com/gratefulagents/sdk/tree/1dc92b73900fac74dc357a938e4b5eee6392b418/pkg/agentsdk/memory

## Contents

- `baseline/events.jsonl`: actual Go task, comment, dependency, claim, close, memory
  upsert/delete and summary events, normalized only for IDs, timestamps and paths.
- `baseline/indexes/*.json`: Go-derived snapshots and a Go-produced embedding cache.
  Cache map keys are normalized consistently with event memory IDs.
- `baseline.sqlite`: schema created by Go's SQLite store, populated with the same
  normalized events and Go-generated little-endian float32 embedding rows.
- `expected.json`, `prime.txt`: actual Go replay/list/filter/prime results, not
  hand-written expectations. `namespace-memory.json` is the distinct Go namespace
  store's phrase-first, any-tag search output with normalized UUIDs/timestamps.
- `manifest.json`: source revision, packages, schema version and normalization scope.
- `verify/main.go`: opens Rust-produced state through the Go APIs, compares outputs
  and then performs a Go write. Run after the crate's `export_roundtrip` example.

Regeneration and bidirectional verification commands are documented in
[`../../docs/project-state.md`](../../docs/project-state.md). Rust conformance tests
read these fixtures without modifying them. The test scenarios are purpose-built;
no claim is made that they represent the complete upstream Go test suite.

- `tools.go` / `tools.json`: actual baseline `pkg/agentsdk/tools/projectstate`
  definitions and task/memory/priming success and error results (including nulls
  and malformed roots), with only generated IDs and
  timestamps normalized. `crates/adk-project-state/src/tool-definitions.json`
  is derived from these same pinned Go tool definitions, under GPL-3.0-only.
